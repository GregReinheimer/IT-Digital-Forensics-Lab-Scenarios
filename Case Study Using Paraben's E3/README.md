# Case Study Using Paraben's E3


## Objective

Then investigating the Windows drive image and conducting forensic analysis by using Paraben's E3 to explore: NTFS file system, Windows Registry on Windows 10 drive image, and Windows artifacts (link files and browser history.

## Business Scenario

CHANGE - A company's Information Technology department received an alert indicating that an employee's workstation has accessed several restricted company folders outside of the employee's normal working hours. The folders contain proprietary financial reports, internal business documents, and customer related information. Security logs showed several unusual file-access events occurring late at night shortly before a large amount of data was copied from an employee's workstation. Management was concerned that the employee's computer may have been used to access or copy proprietary information without authorization. The company also discovered a USB storage device had recently been connected to the workstation.

Since the activity could represent a violation of the company's acceptable-use and information security policies, the company's IT security manager authorized a digitial forensic investigation.
